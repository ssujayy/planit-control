# Claude Code — PlanIT Control

Before working, read AGENTS.md in the repository root in full.
Follow its shared project instructions.

Also read the current task's relevant API contract, schema, fixtures, and module
code. The master team playbook governs project objectives and scheduling;
the verified sponsor brief governs sponsor requirements.

Do not maintain a separate copy of the shared project plan in this file.

For each task:
1. Identify the assigned scope and inspect existing work.
2. Implement the smallest complete change that meets the objective.
3. Coordinate shared-contract changes before making them.
4. Run appropriate checks.
5. Report changed files, results, and remaining gaps.

Proceed with routine work inside the assigned scope. Ask for clarification when
an unresolved decision would change shared architecture, overwrite another
person's work, or conflict with the team's explicit instructions.

Never expose secrets, silently substitute replay for live data, claim unrun
checks passed, or present planned functionality as implemented.
